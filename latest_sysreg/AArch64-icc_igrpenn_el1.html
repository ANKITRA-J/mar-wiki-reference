Interrupt Controller Interrupt Group Enable Registers (EL1)

Parameterized reference to the Interrupt Controller Interrupt Group 0/1 Enable registers (n = 0..1). Select a concrete register below:

  • ICC_IGRPEN0_EL1 — Interrupt Controller Interrupt Group 0 Enable Register
  • ICC_IGRPEN1_EL1 — Interrupt Controller Interrupt Group 1 Enable Register
